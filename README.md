# Глава 0.1 — Структура решения (v1.0)

> **Статус:** Фаза 0, Глава 0.1  
> **Область:** Структура solution, правила зависимостей, порядок создания  
> **Принцип:** ECS только для мира; UI/локализация/ввод/настройки — отдельные ООП-модули; инструменты — отдельный слой.

---

## 1. Общая схема (solution layout)

```text
PixelGame.sln
│
├── src/
│   ├── Core/                 # Ядро: математика, шина событий, логгер, сервис-локатор
│   ├── Animation/            # Общая система анимаций (Game + UI)
│   ├── Localization/         # Тексты, шрифты, шейпинг (Глава 1.x)
│   ├── Input/                # Абстракция действий, привязки (Глава 2.x)
│   ├── Settings/             # Конфиги, сохранение/загрузка
│   ├── Game/                 # ECS-мир, компоненты, системы (Глава 3.x)
│   ├── UI/                   # Дерево UI, виджеты, экраны (Глава 5.x)
│   ├── Tools/                # Дебаг-окно, консоль, инспектор ECS (сквозной слой)
│   └── App/                  # Точка входа, Game1, склейка всего
│
├── tests/
│   └── Core.Tests/           # Юнит-тесты для Core (и далее по мере роста)
│
├── assets/                   # Исходные ассеты (не Content Pipeline, а сырьё)
│   ├── fonts/
│   ├── textures/
│   ├── audio/
│   └── data/                 # JSON/CSV локализации, конфиги
│
├── docs/                     # Дизайн-документы, схемы архитектуры
│
├── Build/                    # (опционально) сборочный вывод, если захотим вынести из bin/obj
├── .editorconfig
├── .gitignore
└── README.md
